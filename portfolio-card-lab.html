01 鼠标跟随立体倾斜（JS 驱动）

pointermove 算偏移 → 写 rotateX/rotateY + 高光位置。平滑回正用 transition。最跟手，但需 JS 与 rAF。

实时粒子装置

Three.js · 交互叙事 
// 倾斜内核：偏移 → 角度，写自定义属性，CSS 负责渲染
const card = document.querySelector('#tilt');
card.addEventListener('pointermove', e => {
  const r = card.getBoundingClientRect();      // 缓存到 resize，别每次 move 都读
  const px = (e.clientX - r.left) / r.width  - .5;
  const py = (e.clientY - r.top)  / r.height - .5;
  card.style.setProperty('--rx', (py * -12) + 'deg');
  card.style.setProperty('--ry', (px *  12) + 'deg');
  card.style.setProperty('--mx', (px * 100 + 50) + '%');
  card.style.setProperty('--my', (py * 100 + 50) + '%');
});
card.addEventListener('pointerleave', () => {
  card.style.setProperty('--rx', '0deg');
  card.style.setProperty('--ry', '0deg');  // 平滑回正靠 CSS transition
});
要点：perspective 写在父级（不是卡面）；内容层用 translateZ(40px) 浮起才有景深；will-change:transform 提示合成层；旋转角控制在 5–15°，再大就显假。

  .card{ transition:none; transform:none; }
