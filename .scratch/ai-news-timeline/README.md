## 全批适用的工作流约束（项目现行裁定，不可绕过）

1. **⛔ 改动后不自动跑无头浏览器 / qa 验证。** 默认流程 = 改码 → 构建通过 → 交付；视觉判断由 daidai 自己跑 dev 看。仅当 daidai **当次明确要求**时可跑。
2. **流程 = 改完告知 → daidai 检查 → daidai 决定 commit。** 不自动 commit、不自动 push。
3. **构建命令**：先手动 `mv dist .tmp/dist-old-$(date +%s)`（否则撞批量删除门禁），再
   `HOME=/home/vii ASTRO_TELEMETRY_DISABLED=1 CODEBUDDY_SAFE_DELETE_ENABLED=0 npm run build`。
4. **全站 `<main>` 一律带 `id="main"`**（Base 的键盘跳转链接指向它）。新建页面必须照做。
5. **独立 CSS 文件里不能出现 `:global()`。** 普通 CSS 不走 Astro 编译，`:global(x)` 是无效选择器，浏览器**整条丢弃**。`:global()` 只用于 `.astro` 的 scoped 样式块。
6. **模板里要写的外链属性必须手写。** 项目已有的外链增强插件只作用于 markdown 管线，`.astro` 模板渲染的外链不会自动获得处理。
7. **删除必须先解释；能保留就不删。**
