# 04 — GLM 翻译接入

**What to build:** 中文访客在新闻页读到中文标题与中文摘要（英文原文同时保留）；翻译服务出问题时页面依然可用，只是显示英文并标注未翻译。翻译在抓取管线内完成，且**只翻译新条目**。

**Spec:** `规格-AI新闻订阅-2026-09-15.md` — D7（降级不产生空字段）、D19（模型与端点、免费档物理约束）、D20（粒度与批量）、D21（重试策略）、D31（语言分工）、D36（密钥只存 Secret）
**Blocked by:** 03
**Status:** blocked（等待 03）

## 交付的端到端行为

一次成功的运行后，数据条目除英文原文外还带上**中文标题**与**中文摘要**；中文页并排显示两者，英文页隐藏中文。若翻译服务不可用，本轮条目**标记为未翻译**、中文字段等于英文字段的值，数据文件仍正常写出，页面显示英文并带未翻译提示——**页面不会因此变红或空白**。

## 验收

**内容与粒度**
- [ ] 每条同时产出**中文标题与中文摘要**（不是只译标题）
- [ ] 请求**批量打包**多条，不是一条一请求
- [ ] **只翻译新条目**；已在窗口或近期归档中的条目不重翻
- [ ] 译文与原文**不错位**：任一批次的第 i 条译文对应第 i 条原文

**稳定性（差异化重试）**
- [ ] **限流类错误与服务端错误 → 重试 2 次**，间隔**指数递增**
- [ ] **鉴权类错误 → 立即放弃、不重试**，整个任务以失败状态退出
- [ ] 返回内容不可解析 → 重试 1 次，仍失败则**仅该批次降级**，其余批次继续
- [ ] **单批失败不导致整轮条目全部退化为英文**
- [ ] 每次请求设置**超时**

**幂等（与 07 的「只在内容变化时才提交」联动）**
- [ ] 同一批内容重复翻译得到**完全相同**的输出（解码策略固定为确定性）
- [ ] 模型的深度思考模式**关闭**——翻译不需要它，且成倍消耗免费档额度与时间

**安全（硬规则）**
- [ ] 密钥**只从环境变量读取**；仓库、配置文件、构建产物中**不出现密钥的任何形态**
- [ ] **永不打印**请求头、环境变量、完整错误对象（日志遮罩对变换过的值会失效）
- [ ] 译文按**纯文本**渲染，**禁止对译文字段使用 `set:html`**
- [ ] 送给模型的内容只来自**已公开发布**的新闻条目

**降级可观测**
- [ ] 未翻译条目带布尔标记；页面按标记显示提示，**不靠判空判定**

## 注意

- ⚠️ **免费档的物理约束是选型代价，不是缺陷**：单并发、约 1 请求/秒、生成速度约 20 每秒令牌。**批量请求必须顺序发送**，不能并行。一次完整运行的耗时以分钟计是预期内的。
- ⚠️ **`temperature` 必须为 0。** 否则同批内容每次译文略有差异 → 每次运行都产生 diff → 破坏「只在内容变化时才提交」的幂等性，git 历史每天多一条噪音提交。
- ⚠️ 抓来的标题是**不可信输入**，会进模型上下文；恶意标题可能构成**提示注入**。本例最坏后果只是译文乱掉，**但若译文被当 HTML 渲染，注入内容就升级为 XSS**——这正是上面那条硬规则的由来。
- 结构化输出参数按端点支持情况使用，但**必须保留宽容解析兜底**（模型偶尔仍会把 JSON 包进代码围栏）。
- **数据治理边界**：送出去的必须是**已公开发布**的内容。**别把未发布草稿、私有笔记接进这个管线。**
- 本票**不新增任何 Cloudflare 侧组件**——密钥下发的对象是 CI，不是 Worker。
