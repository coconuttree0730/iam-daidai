# 03 — 抓取管线（含测试缝）

**What to build:** 一个离线运行的抓取管线：从**免费无密钥**的公开源取回一批与 AI 相关的条目，经关键词筛选、时间窗过滤、URL 规范化去重、「热度 × 时间衰减」排序、截断到上限后，落成一份结构正确的数据文件。**本票不含翻译**——中文字段直接等于英文字段的值，并标记为未翻译。

**Spec:** `规格-AI新闻订阅-2026-09-15.md` — D7（降级不产生空字段）、D8（时间字段两枚）、D9（去重主键）、D10（更新时间戳）、D11/D12（窗口与向前合并）、D15（数据源选型）、D16（筛选口径）、D17（不做多源兜底）、D18（静默失败优先）、Testing Decisions 全节
**Blocked by:** None — can start immediately
**Status:** ready-for-agent

## 交付的端到端行为

在开发机上运行一次脚本（**无需任何密钥**），产出一份数据文件：

- 条目数不超过设定上限；
- 同一篇文章**不重复出现**；
- 每条都带可用于时间线定位的时间字段，以及一个稳定的去重主键；
- 与 AI 无关的条目被筛掉，超出时间窗的条目被筛掉；
- 同一天运行两次**不产生重复条目**。

当源站不可用、或抓到的条目少于阈值时，管线**不写入文件并以成功状态退出**，上一次的快照保持不变。

## 验收（全部断言外部可观察行为）

**筛选与排序**
- [ ] 产出条目数不超过设定上限
- [ ] 关键词粗筛生效：与 AI 无关的条目被剔除
- [ ] 时间窗生效：窗外的条目被剔除
- [ ] 排序使「更热或更新」的条目排在更前

**去重**
- [ ] 同一篇文章只出现一次——**追踪参数差异、尾斜杠差异、fragment 差异不产生重复条目**
- [ ] 去重主键是**规范化 URL 的短哈希**；同一篇文章的不同追踪参数形式得到**同一主键**
- [ ] 去重比对范围包含「当前窗口 + 近期被挤出的条目」，**重复运行幂等**

**时间字段**
- [ ] 每条都有「抓取时间」；有原文发布时间的取其值，**缺失时回退为抓取时间**
- [ ] 时间取值是合法、可排序的机器可读形式，**不因缺失而写入空值或非法字符串**
- [ ] 数据文件顶层带一个记录最近一次成功抓取时间的字段

**失败语义与降级**
- [ ] 抓取结果少于阈值时**不写文件、以成功退出**，上一次快照保持不变
- [ ] 中文字段等于英文字段的值，并带**未翻译标记**（**不产生空字段、不靠判空**）

**测试缝（本票的核心交付之一）**
- [ ] 网络调用做成**可注入的形参**——测试注入假响应，**无需真实网络**
- [ ] 测试**一次覆盖整条链路**：解析 → 规范化 → 去重 → 排序 → 截断 → 序列化
- [ ] 测试断言「给定一个响应，输出的数据结构符合契约」
- [ ] 测试断言「给定两条指向同一篇文章的不同 URL，输出只剩一条」
- [ ] 测试断言「给定一条缺发布时间的条目，时间线定位字段回退正确」
- [ ] 测试断言**否定行为**：「源站不可用时**没有**发生写入」
- [ ] **更换内部实现（换解析库、调整函数拆分）时测试不变红**
- [ ] 测试不需要浏览器、不需要网络；形态沿用项目既有的纯函数回归脚本风格（无框架、直接运行、断言失败即非零退出）

## 注意

- **数据源选型是产品决策，不要自行扩源。** 本票只用免费无密钥的源，且**不做多源兜底**——备用源意味着第二套解析器、第二种时间格式、第二个维护面，而同一网络事件往往同时影响多个源。
- **脚本是离线内容生产工具，不是运行时代码。** 它不在站点运行时执行，产物是数据文件（与素材流水线同类）。**线上不会执行 Node**——这是本方案「运行时零 fetch 契约完好」的前提。
- 脚本**不得读取任何密钥**（本票不翻译）。
- **不要为了类型检查改动构建配置**（如往 `tsconfig` 里加目录）。脚本按现状被构建排除即可。
- **静默失败是刻意选择**：宁可展示三天前的新闻，也不展示空白或报错的新闻页。代价是失败不可见——通知兜底由 07 承担。
