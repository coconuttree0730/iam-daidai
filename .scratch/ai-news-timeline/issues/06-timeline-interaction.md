>
> 站长看过冷启动真实产物后裁定改版：**横向轨道 → 纵向时间线**（规格 **D42**，D23 作废）。
> 作废原因：窗口 72h、实测跨度 **23.3h** ⇒ 横轴上**恒为 1 个月 = 1 条 320px 宽的列**，
> 960px 容器里约 **600px 恒空**，还要按 ‹ › 横滚看别的月份；且归档生长后月份列会变成
> 几百条的超长竖列。**「手机手势冲突」那条底线在纵向版式下自动满足**——页面滚动就是
> 浏览器原生滚动，零接管。
>
> **本票作废的验收项**：横向移动 / 左右箭头 / 键盘方向键 / 拖拽跟手 + 阈值 / 容器横滑时页面纵滚 /
> 「按年月分组」（改为**按天**分组）。
> **保留并已交付的**：年份切换零请求（D24）、首屏只渲最新年份（D25）、分组语义、
> 条目可访问名称、外链属性手写、纯文本渲染、独立 CSS 文件、减少动态效果。
> **替换实现**：`>900px` 中央轴左右错位两列 / `≤900px` 左轴单栏，全在 `lab-news.css`
> 的媒体查询里；`ai-news-timeline.js` 只剩年份切换（229 行 → 96 行）。

**What to build:** 访客能沿纵向时间线按天回看条目，能切换年份回看历史；中文页显示中文 + 英文原文对照，英文页只显示英文。

## 交付的端到端行为

> ⚠️ **以下段落写于改版前**，其中「横向 / 横滑 / 箭头 / 方向键 / 拖拽 / 按年月分组」均已作废（见顶部注）。

访客进入新闻页 → 看到一条横向的时间线，条目按年月分组标注 → 能用滚轮横滑区、拖拽、左右箭头按钮、键盘方向键移动它 → 移动时页面本身仍能正常上下滚动（手机上不产生手势冲突）→ 切换到往年，看到该年份的条目，且**不发起任何网络请求** → 点条目外链在新标签打开。

## 验收

**横向交互**
- [ ] 时间线容器可横向移动
- [ ] **页面纵向滚动不被吞掉**——手机上竖向滑动仍能滚页面
- [ ] 左右箭头按钮可驱动横移
- [ ] 键盘方向键可驱动横移，且焦点可见
- [ ] 拖拽跟手；**拖拽位移超过阈值时视为拖拽而非点击，不误触条目链接**
- [ ] 尊重系统的「减少动态效果」偏好（缓动/惯性退化为直接定位）

**定位与年份切换**
- [ ] 条目按年月分组标注，能定位到指定时段
- [ ] 切换年份**只做 DOM 显隐、零网络请求**
- [ ] **默认只渲染当前时段**，不一次性渲染全部历史（数年累积可达数千条）
- [ ] 页面存在多年份数据时，首屏渲染量不随历史总量增长

**条目内容与可访问性**
- [ ] 中文页条目展示：**中文标题 + 中文摘要 + 英文原文**；英文页条目只展示英文
- [ ] 每条标注来源与时间
- [ ] 读屏用户获得正确的分组语义；条目的可访问名称是「标题 + 来源 + 时间」，**不是整段摘要**
- [ ] 译文按**纯文本**渲染，**不使用 `set:html`**

**外链**
- [ ] 外链在新标签打开，并带 `noopener` / `noreferrer` / **`nofollow`**
- [ ] 属性**手工写在模板上**——项目已有的外链增强插件只作用于 markdown 管线，不会覆盖此处

**样式**
- [ ] 样式写在**独立 CSS 文件**中，文件内**不含 `:global()`**
- [ ] 颜色消费既有主题变量，明暗两套主题下都可读

## 注意

- ⚠️（改版后已自动满足，无需实现）**不锁视口高度。** 锁定视口让滚轮全权驱动横移的形态已被明确否决——**它在手机上的手势冲突是致命的**，用户将无法上下滚动页面。本票采用「容器横滑 + 页面正常纵向滚动」。
- **时间线定位取「有原文发布时间则用之，否则回退抓取时间」**——这是渲染不崩的底线。**不要假设该字段必有**，也不要假设其格式统一。
- 拖拽与点击的阈值判定是**必需的**，不是优化项：没有它，用户在条目上轻微拖动就会误触发外链跳转。
- **`nofollow` 是明确要求**：不为抓来的外链做权重背书。
