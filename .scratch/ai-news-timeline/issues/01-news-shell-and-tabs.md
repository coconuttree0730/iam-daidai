# 01 — 时间线骨架：中文新闻页与板块 tab 条

**What to build:** 游乐场的板块落点页与新的新闻页之间，用一个共享的 tab 条把两者在视觉上绑成一组、互为链接；中文访客从游乐场能直接看到「实验 / 新闻」两个入口，进入新闻页看到一个体面的空状态，而不是空白、不是报错、不是 404。**本票只交付骨架与空状态，不接任何真实数据**——数据由 03 之后的票注入。

**Spec:** `规格-AI新闻订阅-2026-09-15.md` — D1（路由拓扑）、D2（导航构件）、D3（编号语义）、D4（新闻不进实验条目数据）、D29（空状态必须有）、D30（键集合对称）
**Blocked by:** None — can start immediately
**Status:** ready-for-agent

## 交付的端到端行为

访客打开游乐场板块落点页 → 页头下方多出一条「实验 / 新闻」的 tab 条，当前页的 tab 有明确选中态 → 点「新闻」→ 进入新闻页，页面上是时间线的纵向容器骨架与一句体面的空状态文案，而不是空白或报错。从新闻页点「实验」能回到落点页。

两个板块是**各自独立的 URL**，不是同一页的前端切换——两个地址都能被直接分享、被单独索引、各有自己的 canonical。

## 验收

**导航与骨架**
- [ ] 板块落点页出现 tab 条，两个 tab 可互相跳转，当前页有明确选中态
- [ ] 落点页**保留其既有编号 chip**（不因新增 tab 而删除或改动编号）
- [ ] 新闻页**不出现任何新编号**
- [ ] 新闻页具备时间线的纵向容器骨架（⚠️ 2026-09-15 改版：原「横向容器」已作废，见 06 顶部注）；数据为空时渲染空状态文案，且页头、页脚、键盘跳转链接等结构完整
- [ ] 新闻页的 `<main>` 带 `id="main"`
- [ ] 构建产物中存在新闻页的独立 HTML，且进入 sitemap

**样式**
- [ ] 新增样式位于**独立 CSS 文件**中，该文件内**不含 `:global()`**
- [ ] tab 条的选中态与 hover 态在明暗两套主题下都可读，颜色消费既有的主题变量而非硬编码色值

**i18n**
- [ ] 新增的界面文案键在中文与英文两袋字典中**完全对称**（构建期校验通过）
- [ ] 新闻页的界面控件文案走语言字典，**不硬编码中文**
- [ ] tab 条组件可被英文页复用：至少支持「当前选中项」与「语言树」两个维度的配置

**健壮性**
- [ ] 数据文件**不存在**与**为空数组**两种情况都能构建成功并渲染空状态（构建不因引入失败而变红）

## 注意

- **不要把新闻做成实验条目。** 既有的实验条目数据文件不应被本票改动——新闻是并列的二级板块，不占编号、不进卡片墙。
- **空状态不是可选项。** 它是健壮性底线：任何数据文件被误删时，全站构建不能因此变红。
- 英文侧的实际接线在 02；本票只需把 tab 条做成可复用即可。
